# 网页设计规格模板

按任务需要选用字段，不要求每个小修改都填写完整模板。输出给构建工具时，把约束写成可执行指令；输出给人阅读时，优先用简洁的标题和表格。

## 目标与内容

- **页面目标：** 访客是谁、希望他们完成什么动作、如何判断页面有效。
- **范围：** 首屏、单页或多个页面；明确包含的区块和已有内容。
- **品牌与文案：** 品牌名称、语气、主标题、副标题、导航、按钮、必要的信任信息。未确认的事实标为待确认，不编造客户、数据或奖项。

## 视觉与交互

- **核心概念：** 页面最有辨识度的一个视觉或交互重点，以及它如何帮助解释产品。
- **设计标记：** 背景与文字色值、强调色、字体及备选字体、字号与行高、间距、圆角、边框和阴影。数值应能直接用于实现。
- **布局：** 桌面与手机的元素顺序、容器宽度、网格、断点、图片裁切与文字换行。
- **状态：** 导航、按钮、表单、加载、错误、空状态以及键盘焦点；没有相应元素时省略。
- **动效：** 触发条件、时长、缓动、循环方式、触屏行为及 `prefers-reduced-motion` 降级。

## 媒体与实现

- **素材清单：** 每个图片、视频或模型的用途、来源、授权条件、实际地址和缺失时的替代方案。不要写虚构 URL。
- **3D 决策：** 说明采用 CSS 纵深、预渲染媒体还是真实 WebGL；若用模型，注明格式、来源、加载体积和手机降级。
- **工程约束：** 现有技术栈、允许修改的文件、依赖边界、性能和无障碍要求。用户只要设计时，不把这些写成已经完成的实现。
- **验收：** 可检查的桌面/手机布局、文案、资源、交互及视觉质量标准；记录实际完成的验证与未验证项。
