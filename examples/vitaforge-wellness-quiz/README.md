# Vitaforge Daily wellness quiz

An independent React 18 + Vite + TypeScript + Tailwind CSS 3 + Lucide React demo built from a supplied visual specification. It is an interactive mockup, not a health service.

Run locally:

    npm install
    npm run dev

Build:

    npm run build

The background image and Helvetica Now Var stylesheet load from the URLs supplied in the design brief. They are not stored in this repository. If either remote source is unavailable, the screen uses its specified blue-gray background and the Helvetica fallback stack. The voice control is a visual preview and does not access the microphone.
